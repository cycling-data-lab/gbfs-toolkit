    collect: a polite collector¶

    Experimental

    Part of the experimental data-lake modules (2.1.0). See the overview.

    gbfs_toolkit.collect.Collector polls the station (and vehicle) feeds of some systems and writes what they publish. You call it; it never starts anything by itself.

    What it does and refuses to do¶
    It identifies itself user_agent is required, with no default. Give one that tells an operator whom to write to: "my-lab-gbfs/1.0 (mailto:me@example.org)".
    It respects ttl A GBFS document says how long it stays fresh. The collector will not ask again before that, nor before min_interval (1 s by default). respect_ttl=False exists for tests and for a feed whose ttl you know to be wrong; you then own the load you put on it.
    It backs off A feed that fails is left alone for 2, 4, 8 ... seconds (capped by max_backoff); HTTP retries of 429 and 5xx honour Retry-After. After five failures in a row the feed's URL is looked up again.
    It uses conditional requests ETag and Last-Modified are sent back; a 304 is not stored again.
    It never invents a value A field the feed leaves out is stored empty and typed: Int64 counts, boolean flags, float64 coordinates. Never 0, never True.
    It writes atomically, and never rewrites Each poll of a system is one small fragment file, written to a temporary name and renamed; nothing already written is touched. compact_collected gathers the fragments of each closed day into one file per system and day.
    One bad feed does not stop the rest A failure is logged and reported in the result table, never raised.

    A difference with to_canonical_station_status

    The older gbfs_toolkit.to_canonical_station_status turns a missing is_renting into True (and to_canonical_vehicles a missing is_disabled into False): convenient for a one-off look, wrong for a collection, where a station that publishes nothing must not look open. collect keeps the gap. If you have data from an older collector that wrote those defaults, declare it as an ambiguous_missing_value incident in quality.

    Layout and compaction¶

    <out_dir>/station_status/<system_id>/_fragments/2026-03-01/<time>-<id>.parquet   # one per poll
<out_dir>/station_status/<system_id>/2026-03-01.parquet                          # after compaction
<out_dir>/vehicle_status/<system_id>/...
<out_dir>/metadata/<system_id>/<feed>/<day>.parquet      # with poll_metadata, see history

    A day file rewritten whole at each poll costs more as the day grows (fine for a few hundred stations every minute, not for a large system), so a poll only adds a fragment. compact_collected(out_dir) (also Collector.compact(), gbfs compact and gbfs collect --compact) turns the fragments of every closed UTC day into the day file:

    • atomic: the day file is written to a temporary name and renamed, and only then are the fragments that were read removed, so an interruption loses nothing (at worst a fragment is read twice, and the rows that are identical in every column are kept once);
    • idempotent: with nothing to gather it changes nothing and rewrites nothing; running it twice, or two at once, gives the same day file;
    • safe next to a running collector: a fragment written meanwhile is not read, so it is not removed, and it joins the next compaction. Today's fragments (UTC) are left alone unless include_today=True;
    • a fragment that cannot be read is left in place, with a warning.

    read_collected, and a path given to aggregate or quality, read day files and fragments alike, so compaction is a matter of file count, not of correctness. Pass write="day" to Collector for the previous behaviour. To go further, load the day files into a lake: write_lake("data/collected/station_status", "data/lake") streams them in, a day at a time.

    Example¶

    The getter below stands in for the network, which is how the tests of the module work too; leave get_json out to use HTTP (needs pip install "gbfs-toolkit[fetch,parquet]").

    import tempfile

from gbfs_toolkit.collect import Collector, read_collected

docs = {
    "https://example.org/gbfs.json": {"version": "2.3", "data": {"en": {"feeds": [
        {"name": "station_status", "url": "https://example.org/status.json"},
        {"name": "free_bike_status", "url": "https://example.org/bikes.json"}]}}},
    "https://example.org/status.json": {"ttl": 60, "data": {"stations": [
        {"station_id": "7", "num_bikes_available": 4, "num_docks_available": 8, "is_renting": True},
        {"station_id": "8"}]}},                       # a station that publishes nothing
    "https://example.org/bikes.json": {"ttl": 0, "data": {"bikes": [
        {"bike_id": "b1", "lat": 43.61, "lon": 3.87}]}},
}

out = tempfile.mkdtemp()
collector = Collector(
    {"demo": "https://example.org/gbfs.json"}, out,
    user_agent="docs-example/1.0 (mailto:me@example.org)",
    feeds=("station_status", "vehicle_status"),
    get_json=docs.__getitem__,          # offline; omit to use HTTP
    min_interval=0,
)
print(collector.poll_once()[["feed", "outcome", "rows"]])
print(collector.poll_once()[["feed", "outcome"]])    # the 60 s ttl: station_status is skipped

stations = read_collected(out)
print(stations[["station_id", "num_bikes_available", "is_renting"]])   # station 8: empty, not 0

# Gather the fragments of closed days into day files (today's are left alone by default)
from gbfs_toolkit.collect import compact_collected

print(compact_collected(out).empty)                         # today is still being collected
done = compact_collected(out, include_today=True)           # here we compact it anyway
print(done[["system_id", "day", "fragments", "rows"]])
assert compact_collected(out, include_today=True).empty     # idempotent: nothing left to do
assert len(read_collected(out)) == len(stations)            # and nothing lost

    A bounded loop in your own process (Ctrl-C ends it cleanly):

    # not run in the tests (it would take an hour)
collector.run(interval=60, duration=3600)        # one hour, a poll a minute

    The same from the shell: see the command line.

    API¶

    collect ¶

    A polite collector of GBFS station and vehicle snapshots, written one file per day.

    Experimental

    Part of the experimental data-lake modules added in 2.1.0: names, parameters and output columns may change in a minor release (see the API policy).

    Nothing here runs in the background: you call Collector.poll_once, or Collector.run (a loop in your own process, bounded by a duration or a number of iterations), or the gbfs collect command. What it does, and refuses to do:

    • It identifies itself. A user_agent is required (there is no default): give one that tells the operator whom to write to, for example "my-lab-gbfs/1.0 (mailto:me@example.org)".
    • It respects the feed's ttl. A GBFS document says how long it stays fresh; the collector will not ask again before that, nor before min_interval. A feed that answers with an error is left alone for longer each time (exponential back-off, capped), and HTTP retries honour Retry-After.
    • It never invents a value. A field the feed leaves out is stored empty, typed (Int64 for counts, boolean for flags, float64 for coordinates), never 0 nor True. A station that publishes nothing must not look like an empty or an open station. (This is stricter than gbfs_toolkit.to_canonical_station_status, which defaults a missing is_renting to True.)

    • It writes atomically, and never rewrites what it has already written. Each poll of a system is one small fragment file, written to a temporary name and renamed::

      /station_status//_fragments/2026-03-01/-.parquet

    compact_collected gathers the fragments of each closed day into one file per system and UTC day, atomically and idempotently (running it again changes nothing, and an interruption loses nothing)::

      <out_dir>/station_status/<system_id>/2026-03-01.parquet
  <out_dir>/vehicle_status/<system_id>/2026-03-01.parquet

    read_collected reads day files and fragments alike, and so does a path given to gbfs_toolkit.aggregate or gbfs_toolkit.quality. write="day" restores the earlier behaviour (the day file is rewritten as a whole at each poll: simple, and fine for a few hundred stations at a one-minute cadence, but its cost grows with the day).

    Networking needs the fetch extra and Parquet the parquet extra. For offline work, pass get_json (a url -> dict function): the tests of this module use a local server.

    Examples:

    >>> import tempfile
>>> from gbfs_toolkit.collect import Collector, read_collected
>>> docs = {
...     "https://example.org/gbfs.json": {"version": "2.3", "data": {"en": {"feeds": [
...         {"name": "station_status", "url": "https://example.org/status.json"}]}}},
...     "https://example.org/status.json": {"ttl": 0, "data": {"stations": [
...         {"station_id": "7", "num_bikes_available": 4, "is_renting": 1},
...         {"station_id": "8"}]}},
... }

...     c = Collector({"demo": "https://example.org/gbfs.json"}, out,

    self,
    systems: Mapping[str, str] | pd.DataFrame,
    out_dir: str | Path,
    *,
    user_agent: str,
    feeds: Sequence[str] = ("station_status",),

    retries: int = 2,
    backoff_factor: float = 0.5,
    min_interval: float = 1.0,
    respect_ttl: bool = True,
    max_backoff: float = 3600.0,
    max_workers: int = 4,
    write: str = "fragments",
    get_json: Callable[[str], dict[str, Any]] | None = None,
    session: Any = None,

        raise ValueError(f"write must be one of {WRITE_MODES}, got {write!r}")

        raise ValueError("no system to collect from")

    self.write = write
    self.user_agent = user_agent.strip()
    self.feeds = tuple(dict.fromkeys(feeds))
    self.timeout = float(timeout)
    self.min_interval = float(min_interval)
    self.respect_ttl = respect_ttl
    self.max_backoff = float(max_backoff)
    self.max_workers = max(1, int(max_workers))
    self._get_json = get_json
    self._retries, self._backoff_factor = int(retries), float(backoff_factor)
    self._session = session
    self._clock = clock
    self._now = now or (lambda: pd.Timestamp.now(tz="UTC"))
    self._state: dict[tuple[str, str], _State] = {}
    self._locks: dict[Path, threading.Lock] = {}
    self._lock = threading.Lock()

    def compact(
    self,
    *,
    include_today: bool = False,
    now: Callable[[], pd.Timestamp] | None = None,
) -> pd.DataFrame:
    """Gather the fragments of this collector's feeds into day files (`compact_collected`)."""
    parts = [
        compact_collected(
            self.out_dir,
            kind,
            systems=list(self.systems),
            include_today=include_today,
            now=now or self._now,
        )
        for kind in self.feeds
    ]
    return pd.concat(parts, ignore_index=True)

    def poll_once(self) -> pd.DataFrame:
    """Poll every system and feed once (those still fresh or backing off are skipped).

    Returns
    -------
    pandas.DataFrame
        One row per (system, feed): ``system_id, feed, outcome`` (one of `OUTCOMES`),
        ``rows`` written and ``error`` (text, for ``failed``). A failure never raises: it is
        logged and reported here, so one bad feed does not stop the others.
    """
    tasks = [(s, k) for s in self.systems for k in self.feeds]

    def work(task: tuple[str, str]) -> dict[str, Any]:
        try:
            return self._poll_one(*task)
        except Exception as exc:  # noqa: BLE001 (keep the other systems going)
            _log.exception("[%s] unexpected error on %s", *task)
            return {
                "system_id": task[0],
                "feed": task[1],
                "outcome": "failed",
                "rows": 0,
                "error": f"{type(exc).__name__}: {exc}",
            }

    with ThreadPoolExecutor(max_workers=min(self.max_workers, len(tasks))) as pool:
        rows = list(pool.map(work, tasks))
    return pd.DataFrame(rows, columns=["system_id", "feed", "outcome", "rows", "error"])

    def poll_metadata(self, feeds: Sequence[str] = METADATA_FEEDS) -> pd.DataFrame:
    """Fetch the slowly changing feeds and keep a version only when their content changed.

    Each feed of each system is normalised (``to_canonical_*``), stamped with ``fetched_at``
    and handed to `gbfs_toolkit.history.record_version`, which stores it under
    ``<out_dir>/metadata/<system_id>/<feed>/<UTC day>.parquet`` only if it differs from the
    latest version. Call it once a day; it does not wait for a ``ttl``.

    Returns
    -------
    pandas.DataFrame
        ``system_id, feed, outcome`` (``written``, ``unchanged``, ``unavailable``, ``failed``
        or a `gbfs_toolkit.history.VersionResult` action) and ``error``.
    """
    from gbfs_toolkit.history import record_version
    from gbfs_toolkit.io import normalize as nz
    from gbfs_toolkit.io.fetch import parse_discovery

    bad = [f for f in feeds if f not in METADATA_FEEDS]
    if bad:
        raise ValueError(
            f"unknown metadata feed(s) {bad}; expected a subset of {METADATA_FEEDS}"
        )

    def normalise(feed: str, doc: dict[str, Any], system: str) -> pd.DataFrame:
        if feed == "system_information":
            return pd.DataFrame([nz.to_canonical_system_information(doc, system_id=system)])
        if feed == "station_information":
            return nz.to_canonical_station_info(doc, system_id=system)
        if feed == "vehicle_types":
            return nz.to_canonical_vehicle_types(doc, system_id=system)
        if feed == "system_pricing_plans":
            return nz.to_canonical_pricing_plans(doc, system_id=system)
        return nz.to_canonical_system_regions(doc, system_id=system)

    rows: list[dict[str, Any]] = []
    for system, url in self.systems.items():
        try:
            urls, _ = parse_discovery(self._fetch(url).data)
        except GBFSError as exc:
            _log.warning("[%s] discovery failed: %s", system, exc)
            rows += [
                {"system_id": system, "feed": f, "outcome": "failed", "error": str(exc)}
                for f in feeds
            ]
            continue
        for feed in feeds:
            row = {"system_id": system, "feed": feed, "outcome": "unavailable", "error": None}
            rows.append(row)
            if feed not in urls:
                continue
            try:
                frame = normalise(feed, self._fetch(urls[feed]).data, system)
                frame = frame.assign(fetched_at=self._now())
                folder = self.out_dir / "metadata" / system / feed
                row["outcome"] = record_version(frame, folder).action
            except (GBFSError, ValueError, TypeError, KeyError) as exc:
                _log.warning("[%s] %s failed: %s", system, feed, exc)
                row.update(outcome="failed", error=str(exc))
    return pd.DataFrame(rows, columns=["system_id", "feed", "outcome", "error"])

    def run(
    self,
    *,
    interval: float = 60.0,
    duration: float | None = None,
    max_iterations: int | None = None,
    sleep: Callable[[float], None] = time.sleep,
    on_poll: Callable[[int, pd.DataFrame], None] | None = None,
) -> dict[str, Any]:
    """Poll every ``interval`` seconds for ``duration`` seconds or ``max_iterations`` polls.

    With neither bound it runs until you interrupt it (Ctrl-C ends it cleanly). The loop
    lives in your process; nothing is left running when it returns.

    Returns
    -------
    dict
        ``iterations``, ``rows`` written and ``outcomes`` (a count per outcome).
    """
    if interval <= 0:
        raise ValueError("interval must be positive")
    started = self._clock()
    outcomes: Counter[str] = Counter()
    rows = 0
    iteration = 0
    try:
        while True:
            t0 = self._clock()
            iteration += 1
            result = self.poll_once()
            outcomes.update(result["outcome"])
            rows += int(result["rows"].sum())
            if on_poll is not None:
                on_poll(iteration, result)
            if max_iterations is not None and iteration >= max_iterations:
                break
            pause = max(0.0, interval - (self._clock() - t0))
            if duration is not None and self._clock() - started + pause >= duration:
                break  # the next poll would fall after the end
            sleep(pause)
    except KeyboardInterrupt:
        _log.info("interrupted after %d iteration(s)", iteration)
    return {"iterations": iteration, "rows": rows, "outcomes": dict(outcomes)}

    def read_collected(
    out_dir: str | Path,
    kind: str = "station_status",
    *,
    systems: Iterable[str] | None = None,
    start: str | pd.Timestamp | None = None,
    end: str | pd.Timestamp | None = None,
    on_error: str = "skip",

    """Read what a `Collector` wrote (day files and fragments), for some systems and days.

    ``start`` and ``end`` are UTC days (both inclusive, compared with the file names). An

    identical in every column are counted once.

    --------
    >>> import pandas as pd
    >>> read_collected("/nonexistent/folder").empty
    True
    """
    if kind not in FEED_KINDS:
        raise ValueError(f"kind must be one of {FEED_KINDS}, got {kind!r}")
    if on_error not in ("skip", "raise"):
        raise ValueError("on_error must be 'skip' or 'raise'")
    base = Path(out_dir) / kind
    lo = None if start is None else to_utc([start]).iloc[0].strftime("%Y-%m-%d")
    hi = None if end is None else to_utc([end]).iloc[0].strftime("%Y-%m-%d")
    wanted = None if systems is None else {str(s) for s in systems}
    frames = []
    if base.is_dir():
        require_pyarrow("read_collected")
        for folder in sorted(p for p in base.iterdir() if p.is_dir()):
            if wanted is not None and folder.name not in wanted:
                continue
            for day, (whole, pieces) in _day_files(folder).items():
                if (lo and day < lo) or (hi and day > hi):
                    continue
                day_frames = []
                for f in [*whole, *pieces]:
                    try:
                        day_frames.append(pd.read_parquet(f).astype(_DTYPES[kind], errors="ignore"))
                    except Exception as exc:  # noqa: BLE001 (pyarrow raises several types)
                        if on_error == "raise":
                            raise
                        _log.warning("skipping unreadable file %s: %s", f, exc)
                if whole and pieces and len(day_frames) > 1:  # an interrupted compaction
                    day_frames = [pd.concat(day_frames, ignore_index=True).drop_duplicates()]
                frames.extend(day_frames)
    if not frames:
        return pd.DataFrame(
            columns=_STATION_COLUMNS if kind == "station_status" else _VEHICLE_COLUMNS
        )
    out = pd.concat(frames, ignore_index=True)
    sort = ["fetched_at", "system_id", "station_id" if kind == "station_status" else "vehicle_id"]
    return out.sort_values(sort).reset_index(drop=True)

    def compact_collected(
    out_dir: str | Path,
    kind: str = "station_status",
    *,
    systems: Iterable[str] | None = None,
    include_today: bool = False,
    now: Callable[[], pd.Timestamp] | None = None,
    compression: str = "zstd",
) -> pd.DataFrame:
    """Gather the fragments of each closed UTC day into one file per system and day.

    For every (system, day) that has fragments, the existing day file (if any) and the fragments
    are combined, rows identical in every column are kept once, the rows are sorted by time and
    station (or vehicle), and ``<day>.parquet`` is written atomically; only then are the
    fragments that were read removed. The result is therefore safe against an interruption (at
    worst a fragment is read twice, and its rows are deduplicated by the next compaction),
    **idempotent** (nothing left to gather: nothing changes and no file is rewritten), and safe
    next to a running `Collector` (a fragment written meanwhile is not read, so it is not
    removed; it joins the next compaction). A fragment that cannot be read is left in place
    with a warning. Two compactions at once give the same day file.

    Parameters
    ----------
    out_dir : str or Path
        The folder a `Collector` writes to.
    kind : {"station_status", "vehicle_status"}
    systems : iterable of str, optional
        Only these systems.
    include_today : bool, default False
        Today's (UTC) fragments are left alone by default: that day is still being collected.
    now : callable, optional
        A UTC clock, for tests.

    Returns
    -------
    pandas.DataFrame
        One row per compacted (system, day): ``kind, system_id, day, fragments, rows, path``;
        empty when there is nothing to do.

    Examples
    --------
    >>> import pandas as pd
    >>> compact_collected("/nonexistent/folder").empty
    True
    """
    require_pyarrow("compact_collected")
    import pyarrow as pa
    import pyarrow.parquet as pq

    from gbfs_toolkit.store import _drop_duplicate_rows

    if kind not in FEED_KINDS:
        raise ValueError(f"kind must be one of {FEED_KINDS}, got {kind!r}")
    today = (now or (lambda: pd.Timestamp.now(tz="UTC")))().strftime("%Y-%m-%d")
    wanted = None if systems is None else {str(s) for s in systems}
    id_col = "station_id" if kind == "station_status" else "vehicle_id"
    base = Path(out_dir) / kind
    rows_out: list[dict[str, Any]] = []
    if not base.is_dir():
        return pd.DataFrame(columns=["kind", "system_id", "day", "fragments", "rows", "path"])
    for folder in sorted(p for p in base.iterdir() if p.is_dir()):
        if wanted is not None and folder.name not in wanted:
            continue
        frag_root = folder / _FRAGMENTS
        if not frag_root.is_dir():
            continue
        for day_dir in sorted(p for p in frag_root.iterdir() if p.is_dir()):
            day = day_dir.name
            fragments = sorted(day_dir.glob("*.parquet"))
            if not fragments or (day >= today and not include_today):
                continue
            target = folder / f"{day}.parquet"
            tables, read = [], []
            for f in fragments:
                try:
                    tables.append(pq.ParquetFile(f).read())
                    read.append(f)
                except Exception as exc:  # noqa: BLE001 (pyarrow raises several types)
                    _log.warning("compaction leaves unreadable fragment %s: %s", f, exc)
            if not tables:
                continue
            if target.exists():
                tables.insert(0, pq.ParquetFile(target).read())
            combined = _drop_duplicate_rows(pa.concat_tables(tables, promote_options="default"))
            order = [("fetched_at", "ascending")]
            if id_col in combined.column_names:
                order.append((id_col, "ascending"))
            combined = combined.sort_by(order)

            def write(tmp: Path, table: Any = combined) -> None:
                pq.write_table(table, tmp, compression=compression)

            atomic_write(target, write)
            for f in read:
                f.unlink(missing_ok=True)
            try:
                day_dir.rmdir()
                frag_root.rmdir()
            except OSError:
                pass  # fragments that arrived meanwhile, or unreadable ones: leave them
            rows_out.append(
                {
                    "kind": kind,
                    "system_id": folder.name,
                    "day": day,
                    "fragments": len(read),
                    "rows": int(combined.num_rows),
                    "path": str(target.relative_to(Path(out_dir))),
                }
            )
    return pd.DataFrame(rows_out, columns=["kind", "system_id", "day", "fragments", "rows", "path"])
