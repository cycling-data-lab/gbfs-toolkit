    trips: published trip files¶

    Experimental

    Part of the experimental data-lake modules (2.1.0). See the overview.

    Several operators publish one row per trip as open data, each in its own shape. gbfs_toolkit.trips reads these families into one table, TRIP_COLUMNS:

    Format Operators Files
    lyft Lyft / Motivate: Citi Bike, Divvy, Bluebikes, Bay Wheels, Capital Bikeshare, Nice Ride... the current files (ride_id, started_at, ...) and the older ones (tripduration, starttime, ...; trip_id, from_station_id, ...; Start date, Start station number, ...)
    urban_sharing Urban Sharing: Oslo, Bergen, Trondheim ISO 8601 times with an offset, coordinates inline
    bts Bicycle Transit Systems: Indego, Metro Bike Share the published duration changes unit between years, so it is recomputed from the two times
    velomagg Vélomagg (Montpellier Méditerranée Métropole, open data under the ODbL) Departure, Return, Departure station, Return station, Covered distance (m), Duration (sec.), Manager, ...: local times, the station number in front of the name, text that may be double-encoded

    ride_id is the operator's own trip identifier, never a user's.

    Formats not covered

    A format is added only when its columns have been checked against a real file; none is guessed, because a guessed reader would silently mislabel data. If you have another one, describe its columns once with TripFormat (below), and consider contributing it with a sample file.

    Vélomagg¶

    The Montpellier file publishes one row per trip, with the local time and the operator's station numbers. read_trips(path, tz="Europe/Paris") gives:

    • start_station_id / start_station_name from "002 Comédie" (the number, then the name; a station with no number keeps its name and has an empty id), the same for the return;
    • text repaired when the file is UTF-8 read as Latin-1 and encoded again (ComÃ©die becomes Comédie; a value that is already right is left alone);
    • distance_m from Covered distance (m) and duration_s from Duration (sec.), as published (the duration is not recomputed from the two times: it differs by a few seconds from them);
    • ended_at empty when the file has no return time (a trip still open when the file was cut);
    • is_operator_staff, a nullable boolean carried from the Manager column: True where the operator marks the trip as made by its own staff, False where it does not, empty where the file is empty. The flag is the publisher's, carried as published; this module does nothing else with it. The other formats leave it empty.

    The account column is never read

    The file has an account number (new_account) that tells two trips of one person apart, and a bike number. Neither is carried over, and there is no option to keep them: a column that is not in the format cannot appear in the result. A test checks that no value of the account column reaches the output, whichever reader or format is used. Times and stations can still identify a person when combined, so read the licence and the publisher's terms before releasing anything made from the file.

    Time zones are explicit¶

    Most files publish local wall-clock times without a zone, so tz= (an IANA name such as "America/Chicago") is required for them; there is no default, because UTC would be a silent mistake. Times come out tz-aware UTC. A local time that does not exist (the hour skipped in spring) is moved to the first instant after the change, and one that happens twice (the repeated hour in autumn) is read as the second, standard-time occurrence. Both are flagged in started_at_tz_flag and ended_at_tz_flag ("nonexistent", "ambiguous"), never fixed silently.

    No personal data¶

    Birth year, gender, bike number and account number are dropped, and the schema has no user identifier. member_type is only member or casual.

    Example¶

    import io

import pandas as pd

from gbfs_toolkit.trips import TripFormat, detect_format, normalize_trips, read_trips

current = (
    "ride_id,rideable_type,started_at,ended_at,start_station_id,end_station_id,member_casual\n"
    "r1,electric_bike,2024-03-10 01:50:00,2024-03-10 03:10:00,S1,S2,member\n"      # across the spring change
    "r2,classic_bike,2024-11-03 01:30:00,2024-11-03 01:45:00,S2,,casual\n"          # in the repeated hour
)
trips = read_trips(io.BytesIO(current.encode()), tz="America/New_York", network="demo")
print(trips[["ride_id", "started_at", "duration_s", "started_at_tz_flag", "end_station_id"]])

legacy = pd.DataFrame({"tripduration": [600], "starttime": ["2019-06-01 07:00:00"],
                       "stoptime": ["2019-06-01 07:10:00"], "usertype": ["Subscriber"],
                       "birth year": [1980], "gender": [1], "bikeid": [7]})
assert detect_format(legacy.columns) == "lyft"
print(normalize_trips(legacy, tz="America/New_York").columns.tolist())   # no personal fields

# A format of your own: describe the columns once.
mine = TripFormat("mycity", {"ride_id": ["id"], "started_at": ["debut"], "ended_at": ["fin"]},
                  times_have_offset=True)
raw = pd.DataFrame({"id": [1], "debut": ["2025-01-01T10:00:00+01:00"], "fin": ["2025-01-01T10:05:00+01:00"]})
print(normalize_trips(raw, mine)[["started_at", "duration_s"]])

    # Vélomagg: two invented rows in the published shape (the account column is in the file, not in the result)
velomagg = (
    "Departure,Return,Bike,Departure station,Return station,Covered distance (m),Duration (sec.),"
    "Manager,new_account\n"
    "2025-03-29 23:55:38,2025-03-30 00:12:27,230,001 Place Exemple,002 CafÃ© de la Gare,2909,1001,False,900001\n"
    "2025-06-01 08:00:00,2025-06-01 08:10:00,619,001 Place Exemple,001 Place Exemple,0,600,True,900002\n"
)
ride = read_trips(io.BytesIO(velomagg.encode("utf-8")), tz="Europe/Paris", network="velomagg")
print(ride[["start_station_id", "end_station_name", "distance_m", "is_operator_staff"]])
assert "new_account" not in ride.columns and "900001" not in ride.astype(str).to_csv()

    Large files: iter_trips(path, tz=..., chunksize=500_000) yields normalised chunks, and a .zip (nested zips included) is read member by member.

    API¶

    trips ¶

    Readers for the trip files that operators publish, into one common schema.

    Experimental

    Part of the experimental data-lake modules added in 2.1.0: names, parameters and output columns may change in a minor release (see the API policy).

    Several operators publish one row per trip as open data, each in its own shape. This module reads the families below into the same table, TRIP_COLUMNS:

    lyft the Lyft / Motivate family (Citi Bike, Divvy, Bluebikes, Bay Wheels, Capital Bikeshare, Nice Ride...): the current files (ride_id, started_at, ended_at, start_station_id, start_lat ...) and the older ones (tripduration, starttime, stoptime, start station id ...; trip_id, from_station_id ...; Start date, Start station number ...); urban_sharing the Urban Sharing platform's files (Oslo, Bergen, Trondheim): ISO 8601 times with an offset, coordinates inline; bts the Bicycle Transit Systems files (Indego, Metro Bike Share); velomagg the open-data trip file of the Vélomagg bike share (Montpellier Méditerranée Métropole, ODbL; Departure, Return, Departure station ... with a three-digit station number in front of each name). Times are local (tz="Europe/Paris"), the file's text may be double-encoded (ComÃ©die) and is repaired, the station number becomes the station id, Covered distance (m) becomes distance_m, and the Manager column, which marks the operator's own staff, becomes the boolean is_operator_staff.

    Anything else: describe the columns once with TripFormat and pass it as fmt. No format is guessed beyond these; in particular the module reads no format it has not been shown.

    Time zones are explicit. Most files publish local wall-clock times without a zone, so tz (an IANA name such as "America/Chicago") is required for them: there is no default, because UTC would be a silent mistake. Times come out tz-aware UTC. A local time that does not exist (the hour skipped in spring) is moved to the first instant after the change and one that happens twice (the repeated hour in autumn) is read as the second, standard-time occurrence; both are flagged in started_at_tz_flag / ended_at_tz_flag ("nonexistent", "ambiguous"), never guessed silently.

    No personal data is carried over. Birth year, gender and bike number are dropped, and the common schema has no user identifier; member_type is only member or casual. A column that is not in the format is never read into the result, so the account number of the Vélomagg file (new_account), which tells that two trips are by the same person, cannot come out, and there is no option to keep it. is_operator_staff says whether the operator marked the trip as made by its staff: it is the publisher's own flag, carried as published, and this module does nothing with it.

...     "start_station_id": ["S1"], "end_station_id": ["S2"]})

    def detect_format(columns: Sequence[str]) -> str | None:
    """The name of the `FORMATS` entry whose columns these are, or ``None``.

    Examples
    --------
    >>> detect_format(["ride_id", "started_at", "ended_at", "start_lat", "start_lng"])
    'lyft'
    >>> detect_format(["started_at", "ended_at", "duration", "start_station_latitude"])
    'urban_sharing'
    >>> detect_format(["trip_id", "start_time", "end_time", "start_lon", "passholder_type"])
    'bts'
    >>> detect_format(["Departure", "Return", "Departure station", "Return station"])
    'velomagg'
    >>> detect_format(["a", "b"]) is None
    True
    """
    low = {str(c).lstrip("\ufeff").lower().strip() for c in columns}
    if {"departure", "return", "departure station", "return station"} <= low:
        return "velomagg"
    if {"started_at", "start_station_latitude"} <= low:
        return "urban_sharing"
    if "start_lon" in low and "start_time" in low:
        return "bts"
    lyft = FORMATS["lyft"]
    has_start = any(a.lower() in low for a in lyft.columns["started_at"])
    has_end = any(a.lower() in low for a in lyft.columns["ended_at"])
    return "lyft" if has_start and has_end else None

    def normalize_trips(
    df: pd.DataFrame,
    fmt: str | TripFormat = "auto",
    *,
    tz: str | None = None,
    network: str | None = None,
    source_file: str | None = None,
) -> pd.DataFrame:
    """Rows of one publisher's file, in the common schema `TRIP_COLUMNS`.

    Parameters
    ----------
    df : pandas.DataFrame
        The file as read (any dtypes; ``dtype=str`` is the safest way to read it).
    fmt : str or TripFormat, default "auto"
        A key of `FORMATS`, a `TripFormat`, or ``"auto"`` to use
        `detect_format`.
    tz : str, optional
        IANA zone of the file's local times. Required unless the format's times carry an offset.
    network, source_file : str, optional
        Written into the output columns of the same name.

    Returns
    -------
    pandas.DataFrame
        Rows without a start time are dropped (and counted in the log); nothing else is. A value
        the file does not carry is empty (``<NA>``/``NaN``), not guessed.

    Raises
    ------
    ValueError
        For an unknown or undetectable format, or a missing ``tz``.

    Examples
    --------
    >>> import pandas as pd
    >>> raw = pd.DataFrame({"tripduration": [600], "starttime": ["2020-03-08 02:30:00"],
    ...                     "stoptime": ["2020-03-08 03:10:00"], "usertype": ["Subscriber"],
    ...                     "birth year": [1980], "gender": [1], "bikeid": [7]})
    >>> out = normalize_trips(raw, tz="America/New_York")
    >>> out.loc[0, "started_at_tz_flag"], out.loc[0, "member_type"], "gender" in out.columns
    ('nonexistent', 'member', False)
    """
    if isinstance(fmt, str):
        name = detect_format(list(df.columns)) if fmt == "auto" else fmt
        if name is None:
            raise ValueError(
                f"cannot tell the trip format from the columns {list(df.columns)[:8]}; "
                "pass fmt= (a key of FORMATS or a TripFormat)"
            )
        if name not in FORMATS:
            raise ValueError(f"unknown trip format {name!r}; known: {sorted(FORMATS)}")
        spec = FORMATS[name]
    else:
        spec = fmt
    if not spec.times_have_offset and tz is None:
        raise ValueError(
            f"format {spec.name!r} publishes local times without a zone: pass tz='Area/City' "
            "(for instance tz='America/Chicago')"
        )
    lower = _lookup(df)
    cols = _present(spec, lower)
    for required in ("started_at", "ended_at"):
        if required not in cols:
            raise ValueError(
                f"format {spec.name!r}: no column for {required} in {list(df.columns)[:10]}"
            )

    out = pd.DataFrame(index=df.index)
    for common in TRIP_COLUMNS:
        if common in cols and common not in ("started_at", "ended_at", "is_operator_staff"):
            out[common] = df[cols[common]]
    if spec.split_station:
        for side in ("start", "end"):
            ids, names = f"{side}_station_id", f"{side}_station_name"
            if ids in out or names in out:
                source = out[names] if names in out else out[ids]
                out[ids], out[names] = _split_station(source)
    if spec.repair_text:
        for common in _TEXT:
            if common in out:
                out[common] = _repair_text(out[common])
    for common in _TEXT:
        out[common] = (
            _id_text(out[common])
            if common in out
            else pd.Series(pd.NA, index=df.index, dtype="string")
        )
    for common in _COORDS:
        out[common] = (
            pd.to_numeric(out[common], errors="coerce").astype("float64")
            if common in out
            else pd.Series(np.nan, index=df.index, dtype="float64")
        )

    raw_t = {
        k: pd.to_datetime(df[cols[k]], errors="coerce", format="mixed", utc=spec.times_have_offset)
        for k in ("started_at", "ended_at")
    }
    if spec.times_have_offset:
        started, ended = raw_t["started_at"], raw_t["ended_at"]
        flag_s = flag_e = pd.Series(pd.NA, index=df.index, dtype="string")
    else:
        assert tz is not None
        started, flag_s = _localize(_strip_offset_naive(raw_t["started_at"]), tz)
        ended, flag_e = _localize(_strip_offset_naive(raw_t["ended_at"]), tz)
    out["started_at"], out["ended_at"] = started, ended
    out["started_at_tz_flag"], out["ended_at_tz_flag"] = flag_s, flag_e

    computed = (ended - started).dt.total_seconds()
    published = next((lower[a.lower()] for a in spec.duration_alias if a.lower() in lower), None)
    if published is not None and not spec.recompute_duration:
        seconds = pd.to_numeric(df[published], errors="coerce") * spec.duration_scale
        out["duration_s"] = seconds.where(seconds.notna(), computed).astype("float64")
    else:
        out["duration_s"] = computed.astype("float64")

    out["is_operator_staff"] = (
        _as_flag(df[cols["is_operator_staff"]])
        if "is_operator_staff" in cols
        else pd.Series(pd.NA, index=df.index, dtype="boolean")
    )
    if "member_type" in cols:
        raw_member = df[cols["member_type"]]
        if spec.member_rule is not None:
            member = raw_member.map(spec.member_rule)
        else:
            low = raw_member.astype("string").str.lower().str.strip()
            member = low.map(dict(spec.member_map)).fillna(low) if spec.member_map else low
        out["member_type"] = member.astype("string")
    if "rideable_type" in cols and spec.rideable_map:
        low = out["rideable_type"].str.lower().str.strip()
        out["rideable_type"] = low.map(dict(spec.rideable_map)).fillna(low).astype("string")

    out["network"] = pd.Series(network, index=df.index, dtype="string")
    out["source_file"] = pd.Series(source_file, index=df.index, dtype="string")
    dropped = int(out["started_at"].isna().sum())
    if dropped:
        _log.warning("%d row(s) without a readable start time were dropped", dropped)
    return out.loc[out["started_at"].notna(), TRIP_COLUMNS].reset_index(drop=True)

    def read_trips(
    path: str | Path | Any,
    fmt: str | TripFormat = "auto",
    *,
    tz: str | None = None,
    network: str | None = None,
    chunksize: int = 500_000,
) -> pd.DataFrame:
    """All the trips of a CSV or zip file as one frame (see `iter_trips` for huge files).

    Examples
    --------
    >>> import io
    >>> csv = io.BytesIO(b"trip_id,start_time,end_time,start_lat,start_lon,passholder_type\\n"
    ...                  b"1,2025-01-01 10:00:00,2025-01-01 10:05:00,39.9,-75.1,Walk-up\\n")
    >>> trips = read_trips(csv, tz="America/New_York")
    >>> trips.loc[0, "member_type"], float(trips.loc[0, "duration_s"])
    ('casual', 300.0)
    """
    frames = list(iter_trips(path, fmt, tz=tz, network=network, chunksize=chunksize))
    if not frames:
        return pd.DataFrame(columns=TRIP_COLUMNS)
    return pd.concat(frames, ignore_index=True)
