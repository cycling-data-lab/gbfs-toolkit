# Recipes

Short answers to a task, each a runnable example on synthetic data (they are executed by the test
suite). They use the [data-lake modules](../lake/index.md), which are experimental. For a first walk
through the whole chain, see the [tutorial](../tutorial.md).

| I want to... | Recipe |
|---|---|
| know whether a collection is complete enough to use | [Check the quality of a collection](check-collection-quality.md) |
| turn a month of minute snapshots into 15-minute, hourly and daily tables | [Aggregate a month of snapshots](aggregate-a-month.md) |
| hand a closed period to someone who must be able to trust it, for instance on Zenodo | [Freeze a version for Zenodo](freeze-for-zenodo.md) |
| read the trip files an operator publishes | [Read published trips](read-published-trips.md) |
